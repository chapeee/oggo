# Governance

## Project Model

Oggo currently follows a maintainer-led model.

- Maintainers review and merge pull requests.
- Maintainers set roadmap priorities.
- Community feedback is collected through issues and discussions.

## Decision Process

- Security and stability have highest priority.
- Breaking changes require clear migration notes.
- Major behavior changes should include design notes in the PR.

## Roles

- **Maintainers**
- Review PRs, triage issues, manage releases, enforce project standards.

- **Contributors**
- Propose and implement improvements via issues and pull requests.
