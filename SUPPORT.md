# Support

## Getting Help

- Read the docs in `docs/` first:
- `docs/installation.md`
- `docs/faq.md`
- `docs/self-hosting.md`
- `docs/api-reference.md`

- Search existing issues before opening a new one.
- Open a GitHub Issue for bug reports or feature requests.

## What to Include in a Help Request

- Operating system and version.
- Node.js version.
- Steps to reproduce.
- Expected behavior and actual behavior.
- Screenshots or logs (with secrets removed).

## Security Issues

Do not report security vulnerabilities in public issues.

Use the private process in [SECURITY.md](SECURITY.md).

## Contribution Questions

For workflow, branch style, and PR expectations, see [CONTRIBUTING.md](CONTRIBUTING.md).
