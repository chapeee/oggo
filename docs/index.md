# Oggo Documentation

Welcome to the official documentation for **Oggo**.

Oggo is a production-grade, self-hosted cron job and server management platform with a built-in SSH terminal. It's designed to make managing scripts, automated tasks, and remote servers incredibly simple and visually appealing.
