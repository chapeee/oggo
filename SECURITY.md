# Security Policy

## Supported Versions

We take the security of Oggo seriously. We currently support the latest major release with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Oggo. **please do not open a public issue**. Instead, report it privately by emailing us at **security@oggo.app**.

### What to include in your report

*   **Description**: A detailed description of the vulnerability.
*   **Steps to reproduce**: Step-by-step instructions to reproduce the issue.
*   **Impact**: What could an attacker achieve?
*   **Environment**: Any relevant details about the environment (OS, Node version, etc.).

### Response Timeline

We will acknowledge receipt of your vulnerability report within **48 hours**. We strive to provide a resolution or a timeline for a fix within **7 days** of acknowledgment.

## Safe Harbor

We will not take legal action against you if you act in good faith and follow this policy. We ask that you give us a reasonable amount of time to address the vulnerability before disclosing it publicly.

## Credit

We appreciate the efforts of security researchers and will provide public acknowledgment for responsible disclosures if you desire.
